# 宇宙飛行士になるためのロードマップ

小学4年生から、宇宙飛行士を目指すための学習・進路・経験を長期的に記録するプロジェクトです。

## プロジェクトの目的

- 宇宙・科学・工学への興味を育てる
- 学校での学習、英語、プログラミング、体力づくりを継続する
- 中学・高校・大学・就職の選択肢を調べ、状況に応じて計画を更新する
- 宇宙飛行士だけに進路を限定せず、宇宙・航空・科学技術分野で活躍できる専門性を身につける
- 将来の宇宙飛行士選抜に必要な条件は、応募時点のJAXA等の公式情報で確認する

## 現在の基本方針

- 計画開始：2026年
- 現在：小学4年生
- 高校の目標候補：群馬県立前橋高等学校
- 興味：ブラックホール、宇宙、ゲーム、アニメ
- 好き・得意なこと：算数、体育、スイミング、卓球
- 英語：今後、長期的に伸ばす

| `06_経験・実績` | 科学イベント、作品、発表、課外活動など |
| `07_職業・就職` | 宇宙・航空・科学技術分野の職業や就職先 |

| `99_過去版・アーカイブ` | 過去の計画や更新前の資料 |

## 運用ルール

1. 計画は固定せず、本人の興味・成長・学校制度・選抜条件に応じて更新する。
2. 大きな方針変更は `00_プロジェクト管理/現在の方針.md` に反映する。
3. 重要な変更は `00_プロジェクト管理/更新履歴.md` に日付付きで記録する。
4. 学校・資格・宇宙飛行士選抜など、変わり得る情報は公式情報を優先して確認する。
5. 個人情報や公開したくない記録は、リポジトリを公開せず慎重に扱う。
