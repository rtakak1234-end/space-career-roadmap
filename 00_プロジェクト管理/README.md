# プロジェクト管理

このフォルダでは、宇宙飛行士を目指す長期計画全体の基本方針と運用を管理します。

## ファイル

- `現在の方針.md`：本人の状況、興味、進学方針、今後決めることをまとめます。
- `更新履歴.md`：ロードマップや運用方針の主な変更を日付付きで記録します。
- `README.md`：プロジェクト全体の管理方法を説明します。

## 運用ルール

1. 長期計画は本人の興味・成長・学校制度・宇宙飛行士選抜の条件に合わせて柔軟に更新します。
2. 大きな方針変更は `現在の方針.md` に反映します。
3. 重要な更新は `更新履歴.md` に日付付きで記録します。
4. 過去の重要な計画は必要に応じて `99_過去版・アーカイブ` に保存します。
5. 応募条件などの変わり得る情報は、判断する時点で公式情報を確認します。

## 関連フォルダ

- `01_12年間ロードマップ`：学年・進路段階ごとの計画
- `02_学校・進学`：学校や大学・学部の調査
- `03_学習`：教科・英語・プログラミングなどの学習
- `04_宇宙・科学`：宇宙・科学分野の学習
- `05_体力・健康`：運動や健康習慣
- `06_経験・実績`：イベント、作品、発表、課外活動
- `07_職業・就職`：宇宙・航空・科学技術分野の職業
- `08_情報収集`：公式情報や調査メモ
- `99_過去版・アーカイブ`：過去の計画や資料
